# موقع تبديل الفئات الجامعية - SWAP

## نبذة عن المشروع

موقع إلكتروني يتيح للطلاب الجامعيين تبديل فئات العملي فيما بينهم بطريقة سهلة وآمنة.

## المشكلة التي يحلها الموقع

- الجامعة تنزل فئات العملي للطلاب حسب الترتيب الأبجدي
- يسمح للطلاب بالتبديل بين الفئات لكن بشرط وجود بديل
- التبديل الثنائي: طالب في فئة 5 يريد الذهاب إلى فئة 10، وطالب في فئة 10 يريد الذهاب إلى فئة 5
- التبديل الثلاثي: ثلاثة طلاب يتبادلون الأماكن بشكل دائري

## الميزات الرئيسية

1. **نظام تسجيل دخول وأشتراك**
   - تسجيل بالاسم الثلاثي (عربي)
   -رقم الجامعي
   -سنة الدراسة
   -بريد إلكتروني
   -كلمة مرور

2. **صفحة طلبات التبديل**
   - جدول يعرض الطلاب الراغبين في التبديل
   - ترتيب حسب تاريخ الطلب (القديم له الأولوية)
   - طالب واحد له طلب واحد فقط في كل وقت
   - جداول منفصلة لكل سنة دراسية

3. **الصفحة الشخصية للطالب**
   - الاسم الثلاثي
   - الرقم الجامعي
   - معلومات التواصل (هاتف، بريد، فيس بوك)
   - صورة شخصية

4. **التواصل بين الطلاب**
   - الضغط على اسم الطالب ينقل لصفحة التواصل

##تقنية البناء

- **الواجهة الأمامية**: HTML, CSS, JavaScript, React
- **الواجهة الخلفية**: PHP
- **قاعدة البيانات**: MySQL

##الجداول في قاعدة البيانات

### جدول الطلاب (students)
- id: رقم التعريف
- name: الاسم الثلاثي
- university_id: الرقم الجامعي
- year: سنة الدراسة
- email: البريد الإلكتروني
- password: كلمة المرور
- phone: رقم الهاتف
- facebook: حساب الفيس بوك
- profile_image: صورة الملف الشخصي
- created_at:تاريخ التسجيل

### جدول طلبات التبديل (swap_requests)
- id: رقم الطلب
- student_id: رقم الطالب
- current_section: الفئة الحالية
- desired_section: الفئة المطلوبة
- status: حالة الطلب (pending, matched, completed)
- request_date: تاريخ الطلب
- created_at: تاريخ الإنشاء

##خطوات التشغيل

### الخيار الأول: تشغيل تجريبي (بدون PHP)
افتح ملف `demo.html` باستخدام Live Server - يعمل مباشرة بدون PHP:
```
public/demo.html
```
ملاحظة: هذا الإصدار يستخدم localStorage للتجربة ولا يحتاج خادم.

### الخيار الثاني: تشغيل كامل (مع PHP + MySQL)
1. حمل XAMPP أو WAMP
2. ضع المجلد في htdocs
3. زر: http://localhost/SWAP/public/index.html

##وظائف الموقع

### تسجيل الدخول
- الرقم الجامعي + كلمة المرور

### طلب تبديل
- الطالب يدخل فئته الحالية والفئة المرغوبة
- النظام يبحث تلقائياً عن تطابق
- التبديل الثنائي: 5 ←→ 10
- التبديل الثلاثي: مدعوم

### قواعد مهمة
- كل طالب سنة له جدول منفصل
- الطلب الأقدم له الأولوية
- طالب واحد = طلب واحد فقط
